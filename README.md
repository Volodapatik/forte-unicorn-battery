# Forte Unicorn EV — Чесний калькулятор заряду

Точний калькулятор відсотка батареї для електроскутера **Forte Unicorn EV**.

## Як користуватися

1. Відкрий [додаток онлайн](https://volodapatik.github.io/forte-unicorn-battery/)
2. Або встанови як PWA (на Android: відкрий у Chrome → меню → «Додати на головний екран»)

## Як отримати APK (справжній мобільний додаток)

### Найшвидший спосіб (2 хвилини):

1. Відкрий будь-який онлайн-конвертер, наприклад:
   - [https://www.webintoapp.com/](https://www.webintoapp.com/)
   - або [https://appsgeyser.com/](https://appsgeyser.com/)
2. Вкажи URL: `https://volodapatik.github.io/forte-unicorn-battery/`
3. Завантаж готовий APK

### Через GitHub Actions (для тих, хто хоче сам збирати)

Можна налаштувати Capacitor + GitHub Actions, але для цього потрібен keystore для підпису. Якщо захочеш — напиши, налаштую.

## Технічні деталі

- Кусково-лінійна інтерполяція за опорними точками напруги
- Точність до 0.01 В
- Dark Mode + офлайн (PWA)
- Один файл логіки
